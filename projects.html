Infrastructure

BFR HPC Job Relay

Built a browser tool for submitting, monitoring, and retrieving STAR-CCM+ jobs, replacing manual PBS scripting and file handling between every run. Ten engineers now run CFD through it without touching SSH, with consistent job naming that makes every run traceable.
ML + Numerical Methods

Navier–Stokes Solver, ML-Accelerated

Wrote a 2D incompressible Navier-Stokes solver from scratch (SIMPLE algorithm, validated against Ghia et al.), warm-started by a neural network that predicts the converged flow field directly, cutting solver iterations by up to 13x.
